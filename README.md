# Black Russia Online Bot

Telegram-бот для мониторинга онлайна серверов Black Russia.

## Возможности
- Ответ по команде `/start`, `/online` или слову `онлайн`
- Вывод общего онлайна и списка всех серверов
- Автоматическая отправка изображения `brtools.png` из репозитория
- Корректная обработка лимита Telegram на длину подписи к фото (1024 символа)

## Файлы
- `bot.py` — основной код бота
- `requirements.txt` — зависимости Python
- `Procfile` — конфигурация запуска на хостингах
- `brtools.png` — поместите сюда изображение
- `.env.example` — пример переменных окружения
